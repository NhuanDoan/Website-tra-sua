# React Component Skill

## Goal

Create or improve a reusable React component following the
existing TeaMilk architecture.

## Workflow

1. Understand the component requirement.
2. Search for similar existing components.
3. Identify reusable UI.
4. Identify required props.
5. Define TypeScript types.
6. Determine Server vs Client Component.
7. Implement the smallest component.
8. Handle loading/error/empty states when applicable.
9. Check responsive behavior.
10. Test the component.

## Rules

- Prefer reusable components when reuse is real.
- Do not over-componentize.
- Use explicit TypeScript types.
- Never use `any`.
- Keep business logic out of presentational components.
- Avoid unnecessary abstraction.
- Follow existing styling conventions.
- Do not duplicate existing components.

## Before implementation

Return:

- Existing components considered
- Proposed component
- Props
- State
- Server/client decision
- Files affected

Wait for approval.

## Output

After implementation:

- Component created/changed
- Props
- Behavior
- Validation
- Potential improvements
