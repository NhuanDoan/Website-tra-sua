# Testing Skill

## Goal

Create meaningful tests for TeaMilk functionality.

## Workflow

1. Understand expected behavior.
2. Identify critical paths.
3. Identify normal cases.
4. Identify edge cases.
5. Identify failure cases.
6. Inspect existing test conventions.
7. Write focused tests.
8. Run tests.
9. Diagnose failures.
10. Avoid testing implementation details unnecessarily.

## Test categories

- Happy path
- Empty state
- Invalid input
- Boundary conditions
- User interaction
- Error state
- Regression cases

## Rules

- Follow existing testing tools.
- Do not introduce a testing library unnecessarily.
- Keep tests deterministic.
- Avoid brittle selectors.
- Test behavior rather than implementation details.
- Do not modify production code just to make a test pass.

## Output

Return:

- Tests added
- Behavior covered
- Edge cases
- Test result
- Remaining gaps
